# Installation

Подготовьте актуальный runtime выбранного языка и отдельное виртуальное окружение. Установите зависимости из lock-файла после его добавления в MVP.

Для тестов используйте только синтетические либо обезличенные логи. Перед публикацией правила проверьте синтаксис, целевой backend и отсутствие секретов.
