# Sigma RuleForge

Инструмент для валидации, конвертации и тестирования правил Sigma.

## Возможности

- разбор и проверка YAML;
- нормализация метаданных;
- конвертация в целевые SIEM-форматы;
- тестирование на синтетических и обезличенных логах;
- связь с техниками MITRE ATT&CK.

Качество конвертации измеряется тестовыми наборами, а ошибки должны быть видимы пользователю. Не добавляйте в репозиторий production-логи и секреты.
